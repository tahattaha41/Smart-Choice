## قواعد النشر والمزامنة
- المزامنة الحالية تخص تدوينات posts/؛ لا تفترض أنها تنشر القالب أو الصفحات الثابتة أو إعدادات المدونة.
- لا تفعّل ALLOW_DELETE دون فهمه واختباره وموافقة صريحة.
- لا تضع OAuth tokens أو مفاتيح API في الملفات أو السجلات.
- تعديل القالب يحتاج مسار نشر منفصلًا وآمنًا ونسخة احتياطية.
- بعد كل تعديل: سجل commit، افحص Action، ثم افحص Blogger نفسه.
- نجاح Actions وحده لا يثبت سلامة عرض الموقع.
