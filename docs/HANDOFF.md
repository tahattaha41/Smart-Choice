## 2) المعمارية (مهم)
- Blogger لا تسمح بتثبيت قالب عبر API. **القالب مثبّت مرة واحدة** (`theme/smart-choice-blogger.xml`) وفيه loader يجلب `assets/js/smart-choice.js` من raw.githubusercontent (كاش ≈5 دقائق، مع بديل jsDelivr). السكربت يحقن `assets/css/smart-choice.css` كـ `<style id="sc-css-live">` ويحمّل الخط IBM Plex Sans Arabic. **لذلك أي تعديل على CSS/JS يظهر بلا رفع قالب.**
- المحتوى: `posts/*.md` (مقالات) و`pages/*.md` (صفحات) ← يُزامن إلى Blogger بـ API (workflows blogger-sync و blogger-pages-sync). المقالات: front-matter فيه `title` و`labels` و`publish`.
- **Self-heal:** `assets/content/bundle.json` (يبنيه `scripts/build_content_bundle.py`) يُستخدم لعرض نص الصفحات/المقالات إن تأخر ظهورها.
- الصفحة الرئيسية تُرسم بالكامل من JS (`.sc-home-root`)، ويوجد قسم ثابت احتياطي في القالب. التصميم: ملف `assets/css/smart-choice.css` واحد بمتغيرات (ورق أبيض/كحلي/أزرق كوبالت/خطوط رفيعة، داكن بالتبديل، مفتاح الثيم sc-theme-v3)؛ لا تضف طبقات ترقيع فوقه — عدّل المتغيرات/الكتل. شريط سفلي للموبايل، شريط جانبي للإدارة. حدّد ورقة CSS القديمة من jsDelivr تُزال بالـJS بعد حقن الحي.
- ملف JS الرئيسي عدة IIFE بالترتيب: أيقونات `window.SCI`، تعطيل GA للمالك/الآلي، حقن CSS، محرك الأدوات `init(root)` (+المساعد `assistant()`)، التنقل/التذييل، self-heal، الرئيسية، لوحة الإدارة، ميزات عامة (بحث/أعلى/مشاركة/مقالات ذات صلة)، طبقة الحركة، favicon، الوضع الداكن، طبقة الربح، JSON-LD، وصف meta احتياطي، إشارات الثقة وخريطة الموقع.
- الإدارة `/p/admin.html`: بوابة PBKDF2-SHA256 (يوجد الـ hash فقط في الكود؛ **كلمة السر يعرفها المالك ولا تُكتب في المستودع العام**)، تبويبات: نظرة عامة، المحتوى، الجودة وAdSense، الفحص الفني، المهندس الذكي، الأرباح، الروابط. هذه بوابة واجهة فقط ولا تحمي أسراراً (الصفحة لا تحتوي أسراراً).
- الأدوات: **34 أداة** (33 لها صفحة مستقلة) في `pages/tools.md` (أزرار `data-tab`) ومنطقها في `init(root)`، لكل أداة: دالة حساب، أمثلة EXAMPLES، فئة TAB_CAT، أيقونة TAB، "اقرأ أيضاً" REL، وربط حقول بـ handlers. أضف أداة جديدة = كل هذه النقاط + اختبار في `qa/`.
- المساعد (تبويب «المساعد الذكي»): **محلل قواعد عربي محلي** يفهم 20+ نوع سؤال (ليس نموذجاً توليدياً ولا يرسل بيانات).

## 3) سير العمل الآلي (`.github/workflows`)
| الملف | الدور |
|---|---|
| blogger-sync / blogger-pages-sync | مزامنة المقالات/الصفحات إلى Blogger (حالة في `.blogger-state.json` و`.blogger-pages-state.json`) |
| content-bundle | يعيد بناء bundle.json |
| live-e2e | اختبار Playwright على الموقع الحي (يومياً وبالطلب فقط؛ لا يعمل عند الدفع لأن كثرة الطلبات تحجبه جوجل) ← `reports/live-e2e.txt` (OK/FAIL/WARN/INFO) و`bot-views.json` |
| site-stats | زيارات Blogger API ← `reports/stats.json` و`stats-history.json` |
| quality-audit | فحص AdSense الثابت ← `reports/adsense-audit.*` |
| **site-review** | **كل 6 ساعات:** `site_review.py` (فحص المستودع وإصلاح الحزمة) + `ai_engineer.py` (تشخيص Gemini ← `reports/ai-engineer.md`، وإجراءات آمنة بقائمة بيضاء) + `link_offers.py` (ربط عروض الشراكة بالمقالات ← `assets/content/offer-map.json`) ثم إعادة المزامنة/الفحص عند الحاجة |
| **auto-posts** | **كل 12 ساعة:** `generate_post.py` يكتب مقالاً (900–1200 كلمة) عن أداة محددة من الموقع بـ Gemini مع بوابات جودة (≥700 كلمة، عنوان غير مكرر، يذكر الأداة، بلا عبارات محظورة) ← `posts/auto-*.md` ← مزامنة |
| frontend-assets / theme-validation / blogger-cleanup | مساعدة/يدوية |

## 5) المشاكل التي واجهتنا وكيف حُلّت
- نص غير مرئي في اللقطات: كان خطأ في harness (إزالة @import)، لا في CSS.
- فشل مزامنة المقالات (حدود Blogger): إعادة محاولة + backoff + حفظ الحالة بعد كل مقال + `sleep(8)` قبل إنشاء جديد.
- عدم استقرار e2e (429 من Blogger): `domcontentloaded` + إعادة محاولات + حجب نطاقات الإعلانات/التحليلات داخل الفحص.
- مراجعة AI عبر GitHub Models فشلت (DNS): استُبدلت لاحقاً بـ Gemini API مجاني.
- ads.txt: فحص مذبذب ← الآن OK؛ المالك فعّل ads.txt المخصص بالسطر الصحيح.
- الصفحات «فارغة» بعد طبقة الحركة: كان كود يخفي `.sc-main` الفارغ قبل وصول المحتوى؛ أُزيل.
- **تكرار 325 سطراً بالخطأ** في smart-choice.js بسبب فهرس `function run()` خاطئ؛ اكتُشف باختبار heal وأُعيد بناء الملف. **درس:** تحقق بـ `node --check` + اختبارات qa بعد أي تعديل بـ Python، وتجنّب إعادة التقطيع بفهارس.
- Gemini: اسم نموذج فارغ (`vars.GEMINI_MODEL` غير مضبوط) و503/timeouts ← اكتشاف النماذج تلقائياً + إعادة محاولة + thinkingBudget=0 + مهلات أقصر.
- اتساق الحروف في الإدارة: أُضيف سلّم أحجام واحد وأرقام لاتينية.
- فراغ كبير فوق التذييل: قاعدة القالب `.sc-main{min-height:55vh}` ← override في CSS.
- Google يعرض نسخة قديمة (صفحة واحدة بـ http): طبيعي لموقع جديد؛ المطلوب طلب الفهرسة وإرسال sitemap (على المالك).
- AdSense/Amazon: عرض بطاقات الشراكة في كل الصفحات يضر بالمراجعة ← أُوقفت (`enabled:false`).
